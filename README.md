# One Line, One Laugh: Roast Your Fridge

An entry for the [make.fun bounty](https://make.fun/bounty/u-suzy-one-line-one-laugh-roast-your-fridge-f1063521):
one line, one laugh, roasting my own fridge.

## The line

> My fridge's ice maker sounds like it's chewing gravel, then proudly serves me three cubes.

90 characters, one sentence, one line. The ice maker gets two concrete,
recognisable details — the gravel-crunching racket and the insulting yield of
exactly three cubes — and the twist pays off in the final two words, flipping
"proudly serves me" into a tiny letdown.

## How it works

`main.ts` (Node 22, standard library only, no network, no randomness) writes
exactly that line to `/output/entry.txt`. `NOTES.md` records the full 15-line
shortlist, the criterion-by-criterion scoring against the judge's five criteria
in order, and why this line won.

## Run it

```sh
mkdir -p out && MAKEFUN_OUTPUT_DIR=out node main.ts
cat out/entry.txt
```
